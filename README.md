# Portfolio Website

เว็บไซต์แฟ้มสะสมผลงานออนไลน์สำหรับนักเรียนชั้น ม.3 ที่เตรียมยื่นสมัครเข้าศึกษาต่อชั้น ม.4

## ภาพรวม
เว็บไซต์นี้ออกแบบตามข้อกำหนดใน spec.md โดยมีโครงสร้างหน้าเดียวและเนื้อหาที่สั้น กระชับ และเหมาะสำหรับผู้รับชมที่ต้องการดูข้อมูลอย่างรวดเร็ว

## โครงสร้างหลัก
- Hero section
- About & Education
- Skills
- Awards & Projects
- Activities
- Contact

## วิธีดูหน้าเว็บไซต์
เปิดไฟล์ [index.html](index.html) ในเบราว์เซอร์ หรือรันคำสั่งต่อไปนี้จากโฟลเดอร์โปรเจกต์:

```bash
python3 -m http.server 8000
```

จากนั้นเปิด http://127.0.0.1:8000/index.html

## สิ่งที่ควรปรับให้ตรงกับข้อมูลจริง
- ชื่อ-สกุล
- โรงเรียน
- แผนการเรียนที่ต้องการ
- เกรดเฉลี่ย
- ผลงาน/เกียรติบัตร
- ช่องทางติดต่อ
